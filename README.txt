MLBB DRAFT LAB — FINAL STATIC PACKAGE

1. Cara termudah di Windows: double-click start-local.bat.
2. Alternatif: upload seluruh isi folder ke static hosting (Cloudflare Pages / GitHub Pages).
3. Edit data/heroes.json untuk hero, counter, item, strength/weakness dan angka scoring.
4. Edit data/patches.json untuk patch bawaan. Patch yang ditambah dari UI disimpan di localStorage browser.
5. assets/ disediakan untuk gambar/audio yang Anda berhak gunakan.
6. Website tidak membutuhkan database/server. Semua analyzer berjalan di browser.

CATATAN DATA
