Map & Rotation Guide

00:00–02:00

Amankan lane priority, informasi jungle lawan, dan hindari trade objektif yang tidak perlu.

02:00 Turtle

Roam + Mid bergerak lebih dulu. EXP menjaga wave dan membuka flank. Jungler simpan Retribution.

05:00–08:00

Konversi turret pertama menjadi kontrol jungle. Jangan mengejar kill melewati area tanpa vision.

08:00+ Lord

Push wave samping sebelum contest. Paksa lawan menunjukkan posisi, lalu pilih Lord, pick-off, atau turret.

Late Game

Nilai death timer lebih tinggi daripada kill. Lindungi damage dealer dan jangan membuka fight tanpa resource utama.

Panduan Pengembangan

Menjalankan

Buka index.html langsung, atau gunakan server statis lokal. Tidak ada build step dan tidak ada backend.

Mengubah data

Edit data/heroes.json untuk hero/counter/item dan data/patches.json untuk patch. Bila browser memblokir fetch saat file dibuka langsung, jalankan start-local.bat.

Deploy gratis

Upload seluruh folder ke GitHub Pages atau Cloudflare Pages sebagai static site. Build command kosong; output directory root.

Aset

Versi final ini sengaja memakai artwork CSS/original placeholder, bukan gambar atau audio game berhak cipta. Folder assets/ disiapkan untuk aset yang memang Anda punya izin gunakan.
